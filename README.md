# Vastu Ji releases

Installers for the Vastu Ji desktop app (Windows), and the small file `latest.json` the app reads to learn that a new version is out.

- **To install:** download the newest `VastuJi_<version>_x64-setup.exe` from [Releases](https://github.com/Jatin-Dhir/vastu-ji-releases/releases) and run it. Vastu Ji needs a licence to work.
- **Updates:** once installed, the app looks here when it opens (this can be turned off in Settings, About), asks before installing a new version, and checks that every update is signed by Vastu Ji before it is installed. It sends nothing about you or your work.

There is no source code in this repository.
